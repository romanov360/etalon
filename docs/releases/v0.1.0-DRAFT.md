## Etalon 0.1.0

An open-source silicon photonics design toolkit for photonic integrated
circuits (PICs) — material dispersion models, waveguide mode solvers,
S-parameter photonic circuit simulation, WDM system math, closed-form
optical link budgets for AI-datacenter interconnects, and Monte Carlo
corner/yield analysis. Pure Python (numpy/scipy), Apache-2.0.

This is the first tagged release: 15 modules, 440 tests, 11 runnable
examples, zero heavy dependencies.

### What's in it

**Core engine** — waveguide mode solving (exact slab TE/TM + effective-index
strip/rib, cross-checked by an in-repo semi-vectorial finite-difference
solver), S-parameter component models (couplers, rings, MZI, grating
coupler), a netlist-level circuit solver, an IM-DD link-budget engine
(RIN/shot/PDL/crosstalk penalties, CPO & pluggable presets), WDM
channel-plan tools, and Monte Carlo corner/yield analysis (including
correlated common+differential variation and whole-bank jointly-coupled
yield).

**Measured-data on-ramp** — Touchstone (.sNp) file I/O and least-squares
parameter extraction, so real foundry/VNA/probe-station data drops
straight into the same models as synthetic spectra.

**System-level effects beyond the ideal case** — ring-to-ring thermal
crosstalk (a WDM bank can be physically unlockable, not just
power-inefficient, once neighbor heat is accounted for), closed-form
zero-forcing FFE equalization (with the noise-enhancement cost booked
honestly, not just the ISI benefit), and laser reliability arithmetic
(Arrhenius/FIT/MTTF/wear-out).

### Quality bar

Every module went through at least one independent adversarial review
before being considered done — a fresh reviewer re-derives the physics
from first principles and tries to break the implementation, not just
reads it and nods along. Across seven review rounds, this caught real
bugs: a ring phase-convention error, an RIN-noise level miscalculation
(~0.56 dB hidden optimism at low extinction ratio), a bulk-group-delay
eye-search failure, a Touchstone option-line parsing gap, and a
silent-garbage FFE cursor-lock failure that could report a
plausible-looking but meaningless +63 dB noise-enhancement number with
no error raised. All fixed and pinned as regression tests. See
[CHANGELOG.md](../../CHANGELOG.md) for the detailed record.

CI runs the full test suite, mypy type checking, all 11 examples
end-to-end, and a strict docs-site build on every push.

### Install

```bash
git clone https://github.com/romanov360/etalon.git && cd etalon
uv sync
uv run pytest
```

PyPI publishing (`pip install etalon`) is planned but not yet live.

### Scope, honestly

Everything here is closed-form or semi-analytic physics — fast,
transparent, dependency-free, accurate to the level a system architect
needs for budgeting and corner exploration. It is **not** a substitute
for full-vectorial mode solvers or FDTD for device signoff, and the
presets are published-data-plausible illustrations, not measured silicon.

### What's not in 0.1.0

- Polarization-dependent transmission at the component/circuit level
  (PDL is budgeted as a link-level margin term, not simulated per-mode)
- MMSE/DFE equalization (only zero-forcing FFE)
- No PyPI package yet
