# Etalon v0.2.0

The first release published to PyPI:

```bash
pip install etalon-photonics      # Python 3.10+
```

```python
from etalon_photonics import link, waveguide
```

## What changed since v0.1.0

**The distribution is now `etalon-photonics`, the module
`etalon_photonics`.** The PyPI name `etalon` was claimed on 2026-09-25 by
an unrelated project, five weeks after this repo adopted the name. That
package also occupies the top-level `etalon` import, so shipping a
differently-named distribution that still installed `etalon/` would have
clobbered it for anyone holding both. The project, repository and
documentation keep the Etalon name — a PyPI distribution name is not a
trademark, and only the install and import strings moved.

The import path changing is a breaking change for anyone who cloned
v0.1.0, which is why this is 0.2.0 and not 0.1.1.

**Python 3.10 through 3.13 are now supported**, up from 3.13 only. Nothing
in the source ever required 3.13 — the newest syntax used is `match`
(3.10+), and the floor came from dependency pins set to whatever was
current at authoring time. The full suite passes on all four versions and
CI runs the matrix, so `requires-python` is an audited claim rather than
an assumption. Dependency floors are now `numpy>=2.0` and `scipy>=1.13`.

**The source distribution builds at all**, which it previously did not: a
symlink committed under `docs/research/` pointed at an absolute path on
the author's machine, was dead in every clone, and hard-failed `uv build`.
The sdist is also now scoped to the library, tests, examples and metadata
rather than sweeping in the 18 MB research corpus — 8.3 MB down to 182 KB.

**Releases are cut by pushing a `v*` tag.** The workflow builds, asserts
the tag matches the version in `pyproject.toml`, runs `twine check`, and
uploads over PyPI Trusted Publishing (OIDC). No API token is stored in the
repository.

## Unchanged

The physics, the API surface (beyond the module name), and the quality bar
are exactly as in v0.1.0: 15 modules, 440 tests anchored to analytic or
known values, 13 runnable examples, and at least one independent
adversarial review per module. See [v0.1.0.md](v0.1.0.md) for the engine
itself and [CHANGELOG.md](../../CHANGELOG.md) for the full review record.

## Scope, honestly

Everything here is closed-form or semi-analytic physics — fast,
transparent, dependency-light, accurate to the level a system architect
needs for budgeting and corner exploration. It is **not** a substitute for
full-vectorial mode solvers or FDTD for device signoff, and the presets are
published-data-plausible illustrations, not measured silicon.
